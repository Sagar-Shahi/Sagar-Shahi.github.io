    What it does

    • Workouts with sets, reps and weight, plus automatic volume and CSV export
    • Meals with calories and macros against a daily target, and a weight log with a chart
    • Dashboard with a weekly goal, streak and 7/30/90-day charts drawn as SVG on the server
    • Plan shop with a cart, orders and a My plans page; full plan text goes only to buyers
    • REST API with revocable API keys for workouts, meals, weight and a summary

    Backend at the core

    Every query is scoped to its owner, so other users' records return 404. API keys are shown once and stored hashed, passwords use Argon2, and 162 automated tests plus a GitHub Actions workflow check every change. Checkout is a demo: no payment provider is connected and no money is taken.

    What it does

    • Short links with auto or custom codes, optional expiry, pause and resume
    • UTM tagging done for you, with values cleaned up automatically
    • Analytics for 7, 30 and 90 days: clicks, unique visitors, referrers, devices and campaigns, with bots left out
